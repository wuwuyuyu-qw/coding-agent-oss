# ============================================================
# requirements-dev.txt —— 仅开发/CI 需要的依赖。
#
# [Design Rationale] 为什么和 requirements.txt 分开？
#   - 生产镜像没必要装 pytest（占空间 + 潜在攻击面）；
#   - CI 和本地开发才需要这些工具；
#   - 标准做法：`pip install -r requirements.txt -r requirements-dev.txt`
#     开发机完整装；`pip install -r requirements.txt` 生产只装运行时。
# ============================================================

# 先装所有运行时依赖
-r requirements.txt
